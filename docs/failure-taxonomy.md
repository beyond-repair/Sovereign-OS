# Failure Taxonomy

Every failure category requires Detection → Containment → Recovery → Prevention.

## Governance Failures
- Authority escalation
- Policy drift
- Constitutional bypass

## Agent Failures
- Hallucination
- Recursive execution loops
- Tool misuse

## Knowledge Failures
- Graph poisoning
- Stale evidence
- Provenance loss

## Economic Failures
- Cost explosion
- Liquidity collapse
- Runway degradation

## Human Failures
- Burnout
- Decision fatigue
- Misalignment

## Security Failures
- Credential leakage
- Sandbox escape
- Tenant contamination

All categories are monitored by the Control Plane and Capital Kernel. Critical failures trigger automatic circuit breakers and human escalation.
